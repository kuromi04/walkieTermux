¿Quién responde a qué?

Cada agente escucha el mismo canal P2P con un rol distinto. El router por @mención decide quién contesta según la conversación.

Características

Todo lo que hace único a esta flota

🎯

Ruteo por @mención

Mensajes sin mención los maneja solo el agente primario. Con mención, responde únicamente el agente indicado. Cero "carreras" de respuesta.

🗣️

Notas de voz

Transcribe el audio entrante con Whisper, ejecuta la orden y responde con audio sintetizado por Fish Audio.

🔒

Seguridad anti-inyección

Regla de seguridad por defecto en cada prompt: nunca revelar tokens, rutas ni archivos internos. Rechaza jailbreaks e inyección de prompt.

🕳️

Anti-bucles

Ignora los propios mensajes y los históricos anteriores al arranque. Limita los intercambios consecutivos por remitente.

🛡️

Respaldo de errores

Si el proveedor de IA falla, el agente contesta con un mensaje amistoso en lugar de quedarse en silencio.

🖥️

Hecho para Termux

Compatibilidad con el ecosistema jcode y glibc en Android. Puente de entorno limpio para ejecutar IAs desde Node.js.

Instalación

En marcha en 4 pasos

1

Instala los requisitos en Termux

# Actualiza los paquetes e instala Node.js y Git $ pkg update && pkg upgrade -y $ pkg install nodejs git -y
2

Clona este repositorio

$ git clone https://github.com/kuromi04/walkieTermux.git $ cd walkieTermux
3

Instala las dependencias

$ npm install
4

Lanza tu flota de agentes

# 🟣 Agente primario: maneja todo sin mención $ walkie agent canal:secreto --cli jcode --name "Nika" --prompt "Eres Nika, asistente de atencion al cliente y control de hardware." # 🟢 Investigadora: solo con @Nova $ walkie agent canal:secreto --cli jcode --name "Nova" --prompt "Eres Nova, investigadora web en tiempo real." # 🟡 Desarrolladora: solo con @Kai $ walkie agent canal:secreto --cli jcode --name "Kai" --prompt "Eres Kai, experta en Termux y Bash."
